### Check that you have the same file

Notebook 01 checks this automatically, but you can also check it yourself:

```powershell
# Windows PowerShell
Get-FileHash data\raw\data.diannoutput.qc.tsv -Algorithm SHA256
```
```bash
# macOS / Linux
shasum -a 256 data/raw/data.diannoutput.qc.tsv
```

The output should match the SHA-256 above.

**Windows tip:** turn on File Explorer → View → Show → File name extensions before moving the file. Otherwise renaming can silently produce `...tsv.tsv`.
